# Redesign Existing Projects Skill

> Audit the current design and raise quality without breaking function

**Category:** Process · **License:** MIT · **Version:** 1.0.0
**Tags:** `redesign` `audit` `renewal` `quality`

## What it does

A skill for lifting the design quality of live sites and apps. It audits the current design, identifies generic AI-generated patterns, and applies high-end standards without breaking existing functionality — useful when scoping a renewal or improvement proposal.

This skill is an executable instruction set (`SKILL.md`) you inject into an AI coding agent
(Claude Code, Codex, Gemini CLI, …) so it works with consistent design criteria.

## Use it

1. Download or copy [SKILL.md](SKILL.md)
2. Register it in your agent — see the [injection guide](https://designskill.dev/help/injecting-skills)
3. Browse it with previews on [designskill.dev](https://designskill.dev/skills/redesign-skill)
