# Visual Design Direction Skill

> Distill references into a documented visual direction

**Category:** Generate · **License:** Apache-2.0 · **Version:** 1.0.0
**Tags:** `Visual` `Direction` `Reference`

## What it does

Extracts the shared tone, color, type and texture from scattered references and states them as one visual direction to agree on before design starts.

This skill is an executable instruction set (`SKILL.md`) you inject into an AI coding agent
(Claude Code, Codex, Gemini CLI, …) so it works with consistent design criteria.

## Use it

1. Download or copy [SKILL.md](SKILL.md)
2. Register it in your agent — see the [injection guide](https://designskill.dev/help/injecting-skills)
3. Browse it with previews on [designskill.dev](https://designskill.dev/skills/visual-design-direction)
