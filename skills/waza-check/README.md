**Category:** QA · **License:** MIT · **Version:** 1.0.0

## What it does

A skill for reviewing code diffs, PRs, issue queues, release readiness, commits, pushes, and overall project state — for code review, issue and PR triage, and pre-release checks.

This skill is an executable instruction set (`SKILL.md`) you inject into an AI coding agent
(Claude Code, Codex, Gemini CLI, …) so it works with consistent design criteria.

## Use it

1. Download or copy [SKILL.md](SKILL.md)
2. Register it in your agent — see the [injection guide](https://designskill.dev/help/injecting-skills)
3. Browse it with previews on [designskill.dev](https://designskill.dev/skills/waza-check)
