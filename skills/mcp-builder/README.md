# MCP Builder Skill

> Designing and building MCP servers that connect external services

**Category:** Development · **License:** Apache-2.0 · **Version:** 1.0.0
**Tags:** `mcp` `server` `tool-design` `integration`

## What it does

A skill for building high-quality MCP (Model Context Protocol) servers that let an LLM interact with external services through well-designed tools. Use it when wrapping external APIs or services in either Python (FastMCP) or TypeScript.

This skill is an executable instruction set (`SKILL.md`) you inject into an AI coding agent
(Claude Code, Codex, Gemini CLI, …) so it works with consistent design criteria.

## Use it

1. Download or copy [SKILL.md](SKILL.md)
2. Register it in your agent — see the [injection guide](https://designskill.dev/help/injecting-skills)
