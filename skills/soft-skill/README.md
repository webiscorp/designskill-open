# High-End Visual Design Skill

> Fonts, spacing, shadows, and card structure that read as premium

**Category:** Style · **License:** MIT · **Version:** 1.0.0
**Tags:** `high-end` `visual-design` `spacing` `typography`

## What it does

A skill that pushes output toward high-end agency work by defining the exact fonts, spacing, shadows, card structures, and animations that make a site read as expensive — and by blocking the common default combinations.

This skill is an executable instruction set (`SKILL.md`) you inject into an AI coding agent
(Claude Code, Codex, Gemini CLI, …) so it works with consistent design criteria.

## Use it

1. Download or copy [SKILL.md](SKILL.md)
2. Register it in your agent — see the [injection guide](https://designskill.dev/help/injecting-skills)
3. Browse it with previews on [designskill.dev](https://designskill.dev/skills/soft-skill)
