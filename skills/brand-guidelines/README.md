# Brand Guidelines Skill

> Applying brand colors and typography consistently across artifacts

**Category:** Brand · **License:** Apache-2.0 · **Version:** 1.0.0
**Tags:** `brand` `guidelines` `color` `typography`

## What it does

A skill for applying a defined set of brand colors and typography consistently across artifacts. Use it whenever brand color rules, style guidelines, visual formatting, or company design standards need to be reflected in a document or asset.

This skill is an executable instruction set (`SKILL.md`) you inject into an AI coding agent
(Claude Code, Codex, Gemini CLI, …) so it works with consistent design criteria.

## Use it

1. Download or copy [SKILL.md](SKILL.md)
2. Register it in your agent — see the [injection guide](https://designskill.dev/help/injecting-skills)
3. Browse it with previews on [designskill.dev](https://designskill.dev/skills/brand-guidelines)
