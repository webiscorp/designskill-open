# Industrial Brutalist UI Skill

> Raw interfaces fusing Swiss typography with terminal aesthetics

**Category:** Style · **License:** MIT · **Version:** 1.0.0
**Tags:** `brutalism` `swiss-typography` `experimental` `high-contrast`

## What it does

A skill for building raw, mechanical interfaces that fuse Swiss typographic print with military terminal aesthetics — rigid grids, extreme type-scale contrast, utilitarian color, and analog degradation effects. Suited to opinionated landing pages and experimental work.

This skill is an executable instruction set (`SKILL.md`) you inject into an AI coding agent
(Claude Code, Codex, Gemini CLI, …) so it works with consistent design criteria.

## Use it

1. Download or copy [SKILL.md](SKILL.md)
2. Register it in your agent — see the [injection guide](https://designskill.dev/help/injecting-skills)
3. Browse it with previews on [designskill.dev](https://designskill.dev/skills/brutalist-skill)
