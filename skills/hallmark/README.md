# Hallmark Skill

**Category:** Style · **License:** MIT · **Version:** 1.0.0
**Tags:** `anti-slop` `landing` `design-extraction` `audit`

## What it does

An anti-AI-slop design skill covering greenfield pages, design audits, redesigns, and design extraction from URLs or screenshots. It keeps new apps and landing pages from settling into default combinations.

This skill is an executable instruction set (`SKILL.md`) you inject into an AI coding agent
(Claude Code, Codex, Gemini CLI, …) so it works with consistent design criteria.

## Use it

1. Download or copy [SKILL.md](SKILL.md)
2. Register it in your agent — see the [injection guide](https://designskill.dev/help/injecting-skills)
3. Browse it with previews on [designskill.dev](https://designskill.dev/skills/hallmark)
