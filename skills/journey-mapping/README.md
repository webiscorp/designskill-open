# Journey Mapping & Service Design Skill

**Category:** Research · **License:** MIT · **Version:** 1.0.0

## What it does

A skill for creating alignment diagrams — customer journey maps, service blueprints, experience maps, and empathy maps. Guides diagram type selection, content structure, diagramming syntax, and how to run alignment workshops.

This skill is an executable instruction set (`SKILL.md`) you inject into an AI coding agent
(Claude Code, Codex, Gemini CLI, …) so it works with consistent design criteria.

## Use it

1. Download or copy [SKILL.md](SKILL.md)
2. Register it in your agent — see the [injection guide](https://designskill.dev/help/injecting-skills)
3. Browse it with previews on [designskill.dev](https://designskill.dev/skills/journey-mapping)
