# Web Video Presentation Skill

> Turning an article or script into a video-like 16:9 web presentation

**Category:** Content · **License:** MIT · **Version:** 1.0.0
**Tags:** `presentation` `video-like` `slides` `narration`

## What it does

A skill for turning an article or narration script into a click-driven 16:9 web presentation that reads like a video. It derives the script and outline from the source in one pass and can optionally synthesize narration audio.

This skill is an executable instruction set (`SKILL.md`) you inject into an AI coding agent
(Claude Code, Codex, Gemini CLI, …) so it works with consistent design criteria.

## Use it

1. Download or copy [SKILL.md](SKILL.md)
2. Register it in your agent — see the [injection guide](https://designskill.dev/help/injecting-skills)
3. Browse it with previews on [designskill.dev](https://designskill.dev/skills/web-video-presentation)
