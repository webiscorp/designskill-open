# Empathy Map Skill

> Synthesize user research into a says/thinks/does/feels empathy map

**Category:** Review · **License:** MIT · **Version:** 1.0.0
**Tags:** `Research` `Empathy map` `UX`

## What it does

Turns interviews and observations into a four-quadrant empathy map, converting raw research into insights a team can act on.

This skill is an executable instruction set (`SKILL.md`) you inject into an AI coding agent
(Claude Code, Codex, Gemini CLI, …) so it works with consistent design criteria.

## Use it

1. Download or copy [SKILL.md](SKILL.md)
2. Register it in your agent — see the [injection guide](https://designskill.dev/help/injecting-skills)
3. Browse it with previews on [designskill.dev](https://designskill.dev/skills/empathy-map)
