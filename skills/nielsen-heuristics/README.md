# Nielsen Heuristics Skill

> Evaluate any interface against Nielsen's 10 usability heuristics

**Category:** Review · **License:** MIT · **Version:** 1.0.0
**Tags:** `Heuristics` `Usability` `Review`

## What it does

Nielsen's ten usability heuristics turned into an executable checklist for classifying and rating issues during a review.

This skill is an executable instruction set (`SKILL.md`) you inject into an AI coding agent
(Claude Code, Codex, Gemini CLI, …) so it works with consistent design criteria.

## Use it

1. Download or copy [SKILL.md](SKILL.md)
2. Register it in your agent — see the [injection guide](https://designskill.dev/help/injecting-skills)
3. Browse it with previews on [designskill.dev](https://designskill.dev/skills/nielsen-heuristics)
