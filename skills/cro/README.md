# Conversion Rate Optimization Skill

> Improving conversion on landing, pricing, and form pages

**Category:** Marketing · **License:** MIT · **Version:** 1.0.0

## What it does

A skill for improving conversion on marketing pages and forms — homepages, landing pages, pricing pages, feature pages, and lead capture — by locating drop-off points and proposing fixes.

This skill is an executable instruction set (`SKILL.md`) you inject into an AI coding agent
(Claude Code, Codex, Gemini CLI, …) so it works with consistent design criteria.

## Use it

1. Download or copy [SKILL.md](SKILL.md)
2. Register it in your agent — see the [injection guide](https://designskill.dev/help/injecting-skills)
3. Browse it with previews on [designskill.dev](https://designskill.dev/skills/cro)
