# Design Ops Skill

> Running design sprints, handoff, team rituals, and documentation standards

**Category:** Process · **License:** MIT · **Version:** 1.0.0
**Tags:** `design-ops` `sprint` `handoff` `process`

## What it does

Covers the operational side of design: running design sprints, managing engineering handoff, establishing team rituals, setting documentation standards, and building design QA processes. Focuses on how teams organize work, collaborate with engineering, and ship without losing quality.

This skill is an executable instruction set (`SKILL.md`) you inject into an AI coding agent
(Claude Code, Codex, Gemini CLI, …) so it works with consistent design criteria.

## Use it

1. Download or copy [SKILL.md](SKILL.md)
2. Register it in your agent — see the [injection guide](https://designskill.dev/help/injecting-skills)
3. Browse it with previews on [designskill.dev](https://designskill.dev/skills/design-ops)
