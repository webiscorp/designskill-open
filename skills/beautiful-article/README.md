# Beautiful Article Skill

> Turning URLs, PDFs, and docs into a shareable single-file HTML article

**Category:** Content · **License:** MIT · **Version:** 1.0.0
**Tags:** `article` `single-file-html` `document-design` `sharing`

## What it does

A skill for editing and designing supplied material — web URLs, PDFs, DOCX, Markdown, plain text, or screenshots — into a readable single-file HTML article that opens offline and can be shared as-is.

This skill is an executable instruction set (`SKILL.md`) you inject into an AI coding agent
(Claude Code, Codex, Gemini CLI, …) so it works with consistent design criteria.

## Use it

1. Download or copy [SKILL.md](SKILL.md)
2. Register it in your agent — see the [injection guide](https://designskill.dev/help/injecting-skills)
3. Browse it with previews on [designskill.dev](https://designskill.dev/skills/beautiful-article)
