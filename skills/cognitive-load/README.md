# Cognitive Load Skill

> Diagnose screen complexity through intrinsic, extraneous and germane load

**Category:** Review · **License:** MIT · **Version:** 1.0.0
**Tags:** `Cognitive load` `Simplify` `UX`

## What it does

Applies cognitive load theory to interfaces, splitting the vague feeling of complexity into three measurable kinds so you know what to remove.

This skill is an executable instruction set (`SKILL.md`) you inject into an AI coding agent
(Claude Code, Codex, Gemini CLI, …) so it works with consistent design criteria.

## Use it

1. Download or copy [SKILL.md](SKILL.md)
2. Register it in your agent — see the [injection guide](https://designskill.dev/help/injecting-skills)
3. Browse it with previews on [designskill.dev](https://designskill.dev/skills/cognitive-load)
