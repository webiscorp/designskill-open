# Interaction Design Skill

> Designing microinteractions, state machines, gestures, and error prevention

**Category:** Design · **License:** MIT · **Version:** 1.0.0
**Tags:** `interaction` `microinteraction` `state-machine` `animation`

## What it does

A skill for specifying how a product responds to user input. Covers microinteractions, animation, state machines, gesture patterns, and error prevention using established interaction design principles, and pushes you to describe behavior across every state and context.

This skill is an executable instruction set (`SKILL.md`) you inject into an AI coding agent
(Claude Code, Codex, Gemini CLI, …) so it works with consistent design criteria.

## Use it

1. Download or copy [SKILL.md](SKILL.md)
2. Register it in your agent — see the [injection guide](https://designskill.dev/help/injecting-skills)
3. Browse it with previews on [designskill.dev](https://designskill.dev/skills/interaction-design)
