# Minimalist UI Skill

> Warm monochrome, typographic contrast, and flat bento grids

**Category:** Style · **License:** MIT · **Version:** 1.0.0
**Tags:** `minimalist` `monochrome` `bento-grid` `editorial`

## What it does

A skill for clean, editorial-leaning interfaces built on a warm monochrome palette, typographic contrast, flat bento grids, and muted pastels. It avoids gradients and heavy shadows so content stays in front.

This skill is an executable instruction set (`SKILL.md`) you inject into an AI coding agent
(Claude Code, Codex, Gemini CLI, …) so it works with consistent design criteria.

## Use it

1. Download or copy [SKILL.md](SKILL.md)
2. Register it in your agent — see the [injection guide](https://designskill.dev/help/injecting-skills)
3. Browse it with previews on [designskill.dev](https://designskill.dev/skills/minimalist-skill)
