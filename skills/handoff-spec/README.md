# Developer Handoff Spec Skill

> Write handoff specs covering measurements, behaviors, assets and edge cases

**Category:** Transform · **License:** MIT · **Version:** 1.0.0
**Tags:** `Handoff` `Spec` `Collaboration`

## What it does

Structures the spec a designer hands to engineering — measurements, state transitions, required assets and the edge cases that usually get missed.

This skill is an executable instruction set (`SKILL.md`) you inject into an AI coding agent
(Claude Code, Codex, Gemini CLI, …) so it works with consistent design criteria.

## Use it

1. Download or copy [SKILL.md](SKILL.md)
2. Register it in your agent — see the [injection guide](https://designskill.dev/help/injecting-skills)
3. Browse it with previews on [designskill.dev](https://designskill.dev/skills/handoff-spec)
