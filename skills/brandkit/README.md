# Brand Kit Skill

> Generating brand guideline boards, logo systems, and identity decks

**Category:** Brand · **License:** MIT · **Version:** 1.0.0
**Tags:** `brand-kit` `identity` `logo` `guideline-board`

## What it does

A skill for producing premium brand-kit imagery — brand guideline boards, logo systems, identity decks, and visual-world presentations — in a minimalist, cinematic, editorial tone. Useful when a brand proposal or identity round needs visual material.

This skill is an executable instruction set (`SKILL.md`) you inject into an AI coding agent
(Claude Code, Codex, Gemini CLI, …) so it works with consistent design criteria.

## Use it

1. Download or copy [SKILL.md](SKILL.md)
2. Register it in your agent — see the [injection guide](https://designskill.dev/help/injecting-skills)
3. Browse it with previews on [designskill.dev](https://designskill.dev/skills/brandkit)
