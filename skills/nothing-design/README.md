# Nothing Design System Skill

> Nothing's dot-matrix, monochrome design language

**Category:** Style · **License:** MIT · **Version:** 1.0.0
**Tags:** `nothing` `dot-matrix` `monochrome` `design-system`

## What it does

A skill for applying the Nothing design system. It triggers only when the user explicitly asks for the Nothing style, and follows its distinctive dot-matrix typography and monochrome-led visual language.

This skill is an executable instruction set (`SKILL.md`) you inject into an AI coding agent
(Claude Code, Codex, Gemini CLI, …) so it works with consistent design criteria.

## Use it

1. Download or copy [SKILL.md](SKILL.md)
2. Register it in your agent — see the [injection guide](https://designskill.dev/help/injecting-skills)
3. Browse it with previews on [designskill.dev](https://designskill.dev/skills/nothing-design)
