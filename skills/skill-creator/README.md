# Skill Creator Skill

> Creating, improving, and benchmarking skills

**Category:** Meta · **License:** Apache-2.0 · **Version:** 1.0.0
**Tags:** `skill-creation` `eval` `benchmark` `meta`

## What it does

A skill for building new skills from scratch, editing and improving existing ones, and measuring their performance. Guides skill structure, running evals, and benchmarking including variance analysis.

This skill is an executable instruction set (`SKILL.md`) you inject into an AI coding agent
(Claude Code, Codex, Gemini CLI, …) so it works with consistent design criteria.

## Use it

1. Download or copy [SKILL.md](SKILL.md)
2. Register it in your agent — see the [injection guide](https://designskill.dev/help/injecting-skills)
3. Browse it with previews on [designskill.dev](https://designskill.dev/skills/skill-creator)
