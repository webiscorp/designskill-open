# Design Taste Frontend Skill

> Reads the brief, infers direction, and ships non-templated interfaces

**Category:** Style · **License:** MIT · **Version:** 1.0.0
**Tags:** `design-direction` `landing` `portfolio` `anti-template`

## What it does

A skill for landing pages, portfolios, and redesigns that avoids templated results. It reads the brief, infers an appropriate design direction on its own, and then ships the interface — aimed at the problem of every brief producing the same screen.

This skill is an executable instruction set (`SKILL.md`) you inject into an AI coding agent
(Claude Code, Codex, Gemini CLI, …) so it works with consistent design criteria.

## Use it

1. Download or copy [SKILL.md](SKILL.md)
2. Register it in your agent — see the [injection guide](https://designskill.dev/help/injecting-skills)
3. Browse it with previews on [designskill.dev](https://designskill.dev/skills/taste-skill)
