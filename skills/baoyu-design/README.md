# Baoyu Design Skill

> High-quality web design standards and implementation guidance

**Category:** Style · **License:** MIT · **Version:** 1.0.0
**Tags:** `web-design` `standards` `layout` `typography`

## What it does

A skill that defines high-quality web design standards and guides implementation against them, providing judgment criteria for layout, typography, and color so results don't drift toward the generic.

This skill is an executable instruction set (`SKILL.md`) you inject into an AI coding agent
(Claude Code, Codex, Gemini CLI, …) so it works with consistent design criteria.

## Use it

1. Download or copy [SKILL.md](SKILL.md)
2. Register it in your agent — see the [injection guide](https://designskill.dev/help/injecting-skills)
3. Browse it with previews on [designskill.dev](https://designskill.dev/skills/baoyu-design)
