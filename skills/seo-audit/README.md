## What it does

A skill for auditing and diagnosing a site's SEO problems — technical SEO checks, analysis of why pages aren't ranking, and prioritized remediation. Useful for establishing a baseline before a renewal.

This skill is an executable instruction set (`SKILL.md`) you inject into an AI coding agent
(Claude Code, Codex, Gemini CLI, …) so it works with consistent design criteria.
