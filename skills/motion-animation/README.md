# Motion & Animation Skill

> Design UI motion with the 12 principles, easing and spring physics

**Category:** Generate · **License:** MIT · **Version:** 1.0.0
**Tags:** `Motion` `Animation` `Easing`

## What it does

Applies the twelve animation principles to interfaces, with easing, spring physics and duration guidance for fixing awkward or excessive motion.

This skill is an executable instruction set (`SKILL.md`) you inject into an AI coding agent
(Claude Code, Codex, Gemini CLI, …) so it works with consistent design criteria.

## Use it

1. Download or copy [SKILL.md](SKILL.md)
2. Register it in your agent — see the [injection guide](https://designskill.dev/help/injecting-skills)
