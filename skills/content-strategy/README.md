# Content Strategy Skill

**Category:** Marketing · **License:** MIT · **Version:** 1.0.0
**Tags:** `content-strategy` `topic-selection` `editorial-plan` `marketing`

## What it does

A skill for building a content strategy — deciding what content to create, which topics to cover, and in what order to publish, with reasoning behind each choice.

This skill is an executable instruction set (`SKILL.md`) you inject into an AI coding agent
(Claude Code, Codex, Gemini CLI, …) so it works with consistent design criteria.

## Use it

1. Download or copy [SKILL.md](SKILL.md)
2. Register it in your agent — see the [injection guide](https://designskill.dev/help/injecting-skills)
3. Browse it with previews on [designskill.dev](https://designskill.dev/skills/content-strategy)
