## What it does

A skill for planning and restructuring a website's page hierarchy, navigation, URL structure, and internal linking — used when designing a sitemap or reorganizing information architecture.

This skill is an executable instruction set (`SKILL.md`) you inject into an AI coding agent
(Claude Code, Codex, Gemini CLI, …) so it works with consistent design criteria.
