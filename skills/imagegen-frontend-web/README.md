# Web Frontend Imagegen Skill

> Generating web screen mockup images before implementation

**Category:** Implementation · **License:** MIT · **Version:** 1.0.0
**Tags:** `mockup-generation` `frontend` `mockup` `imagegen`

## What it does

A skill for generating web screen mockup images ahead of frontend work, so the target screen is fixed as an image before code is written and implementation quality can be judged against it.

This skill is an executable instruction set (`SKILL.md`) you inject into an AI coding agent
(Claude Code, Codex, Gemini CLI, …) so it works with consistent design criteria.

## Use it

1. Download or copy [SKILL.md](SKILL.md)
2. Register it in your agent — see the [injection guide](https://designskill.dev/help/injecting-skills)
3. Browse it with previews on [designskill.dev](https://designskill.dev/skills/imagegen-frontend-web)
