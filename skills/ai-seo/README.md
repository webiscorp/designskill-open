## What it does

A skill for optimizing content for AI search engines so it gets cited and surfaced in LLM-generated answers, adjusting document structure and phrasing accordingly. Covers AEO, GEO, and LLM optimization.

This skill is an executable instruction set (`SKILL.md`) you inject into an AI coding agent
