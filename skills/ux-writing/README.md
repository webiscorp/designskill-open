# UX Writing Skill

> Writing interface copy for buttons, errors, onboarding, and empty states

**Category:** Content · **License:** MIT · **Version:** 1.0.0
**Tags:** `ux-writing` `microcopy` `error-message` `onboarding`

## What it does

A skill for writing user-centered, accessible interface copy for digital products. Covers buttons, labels, error messages, notifications, forms, onboarding, empty states, success messages, and help text — every string a user reads.

This skill is an executable instruction set (`SKILL.md`) you inject into an AI coding agent
(Claude Code, Codex, Gemini CLI, …) so it works with consistent design criteria.

## Use it

1. Download or copy [SKILL.md](SKILL.md)
2. Register it in your agent — see the [injection guide](https://designskill.dev/help/injecting-skills)
3. Browse it with previews on [designskill.dev](https://designskill.dev/skills/ux-writing)
