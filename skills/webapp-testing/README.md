# Webapp Testing Skill

> Verifying, debugging, and capturing local web apps with Playwright

**Category:** QA · **License:** Apache-2.0 · **Version:** 1.0.0
**Tags:** `testing` `playwright` `screenshot` `debugging`

## What it does

A toolkit skill for driving and testing local web applications with Playwright. Supports verifying frontend behavior, debugging UI, capturing browser screenshots, and reading browser logs — useful whenever a change needs real rendered verification.

This skill is an executable instruction set (`SKILL.md`) you inject into an AI coding agent
(Claude Code, Codex, Gemini CLI, …) so it works with consistent design criteria.

## Use it

1. Download or copy [SKILL.md](SKILL.md)
2. Register it in your agent — see the [injection guide](https://designskill.dev/help/injecting-skills)
3. Browse it with previews on [designskill.dev](https://designskill.dev/skills/webapp-testing)
