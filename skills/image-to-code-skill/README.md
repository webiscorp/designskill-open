# Image to Code Skill

> Generate the design image first, then implement it faithfully

**Category:** Implementation · **License:** MIT · **Version:** 1.0.0
**Tags:** `image-to-code` `implementation` `fidelity` `workflow`

## What it does

For visually important web work, this skill generates the design image first, analyzes it in depth, and then implements the page to match. It prevents the flat results that come from writing code before the target screen exists.

This skill is an executable instruction set (`SKILL.md`) you inject into an AI coding agent
(Claude Code, Codex, Gemini CLI, …) so it works with consistent design criteria.

## Use it

1. Download or copy [SKILL.md](SKILL.md)
2. Register it in your agent — see the [injection guide](https://designskill.dev/help/injecting-skills)
3. Browse it with previews on [designskill.dev](https://designskill.dev/skills/image-to-code-skill)
