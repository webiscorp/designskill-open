# Brand Naming Skill

> A naming process from candidate generation to trademark and domain checks

**Category:** Generate · **License:** Apache-2.0 · **Version:** 1.0.0
**Tags:** `Branding` `Naming` `Strategy`

## What it does

A systematic way to generate and filter brand name candidates across pronunciation, meaning, trademark and domain — so naming stops being a taste fight.

This skill is an executable instruction set (`SKILL.md`) you inject into an AI coding agent
(Claude Code, Codex, Gemini CLI, …) so it works with consistent design criteria.

## Use it

1. Download or copy [SKILL.md](SKILL.md)
2. Register it in your agent — see the [injection guide](https://designskill.dev/help/injecting-skills)
3. Browse it with previews on [designskill.dev](https://designskill.dev/skills/brand-naming)
