# Design QA Checklist Skill

> Generate QA checklists that verify implementation against the design

**Category:** Review · **License:** MIT · **Version:** 1.0.0
**Tags:** `QA` `Checklist` `Verification`

## What it does

Generates QA checklists that catch gaps between design intent and shipped implementation — spacing, type, states and responsive behavior per screen.

This skill is an executable instruction set (`SKILL.md`) you inject into an AI coding agent
(Claude Code, Codex, Gemini CLI, …) so it works with consistent design criteria.

## Use it

1. Download or copy [SKILL.md](SKILL.md)
2. Register it in your agent — see the [injection guide](https://designskill.dev/help/injecting-skills)
3. Browse it with previews on [designskill.dev](https://designskill.dev/skills/design-qa-checklist)
