# Gestalt Principles Skill

> Judge layouts with proximity, similarity, continuity and closure

**Category:** Review · **License:** MIT · **Version:** 1.0.0
**Tags:** `Gestalt` `Layout` `Perception`

## What it does

A guide to the Gestalt grouping principles behind how the eye assembles elements — useful when laying out cards and sections or diagnosing a disorganized screen.

This skill is an executable instruction set (`SKILL.md`) you inject into an AI coding agent
(Claude Code, Codex, Gemini CLI, …) so it works with consistent design criteria.

## Use it

1. Download or copy [SKILL.md](SKILL.md)
