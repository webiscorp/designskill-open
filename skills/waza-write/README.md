# Waza Write Skill

> Rewriting prose and removing AI-like wording

**Category:** Content · **License:** MIT · **Version:** 1.0.0
**Tags:** `rewriting` `copy` `localization` `release-notes`

## What it does

A skill for rewriting and polishing prose in drafts, docs, release notes, and launch copy. It strips AI-sounding wording and reviews product localization copy while preserving the original intent.

This skill is an executable instruction set (`SKILL.md`) you inject into an AI coding agent
(Claude Code, Codex, Gemini CLI, …) so it works with consistent design criteria.

## Use it

1. Download or copy [SKILL.md](SKILL.md)
2. Register it in your agent — see the [injection guide](https://designskill.dev/help/injecting-skills)
3. Browse it with previews on [designskill.dev](https://designskill.dev/skills/waza-write)
